# 控件间距规范

本规范定义了NyaLauncher Avalonia应用中所有控件的间距标准，基于实际项目代码分析制定，确保界面的一致性和可维护性。

## 基础间距系统

采用**2px为基础单位**的间距系统，支持常用间距值。

### 间距变量

| 变量名 | 值 | 用途 | 使用频率 |
|--------|-----|------|----------|
| `xxs` | 2px | 极小间距，图标与文字微调、紧密元素 | 高 |
| `xs` | 4px | 最小间距，紧凑元素内部、小分隔 | 高 |
| `sm` | 8px | 小间距，相关元素之间、按钮组间距 | 高 |
| `md` | 12px | 中等间距，一般元素分隔、卡片内边距 | 高 |
| `lg` | 16px | 大间距，区块内部padding、主要分隔 | 高 |
| `xl` | 24px | 超大间距，区块之间分隔、标题下方 | 中 |
| `xxl` | 32px | 特大间距，页面级布局、大区域分隔 | 中 |
| `xxxl` | 48px | 巨大间距，特殊场景 | 低 |

### 常用特殊值

| 值 | 用途 | 使用场景 |
|-----|------|----------|
| `3px` | 微调间距 | 图标与文字、小元素间距 |
| `5px` | 小间距 | 紧凑布局中的分隔 |
| `7px` | 中小间距 | 按钮内边距、小卡片 |
| `9px` | 中间距 | 状态指示器间距 |
| `10px` | 中间距 | 对话框内容间距、列间距 |
| `14px` | 中大间距 | 卡片内边距、列表项间距 |
| `18px` | 大间距 | 滚动区域边距、大卡片 |
| `20px` | 大间距 | 页面区域分隔 |
| `22px` | 超大间距 | 对话框内边距 |
| `26px` | 超大间距 | 对话框内容边距 |
| `28px` | 巨大间距 | 登录框内边距 |

## 控件间距规范

### 按钮 (Button)

| 类型 | Padding | CornerRadius | 说明 |
|------|---------|--------------|------|
| 主要按钮 | `12, 6` | 4px | 标准按钮 |
| 窗口按钮 | `10, 0` 或 `14, 7` | 7px | 窗口控制按钮 |
| 小按钮 | `8, 4` | 4px | 紧凑场景 |
| 按钮组间距 | `0, 0, 8, 0` | - | 按钮之间水平间距 |
| 单独按钮下方 | `0, 4, 0, 0` | - | 单独按钮下方间距 |

### 文本框 (TextBox)

| 属性 | 值 | 说明 |
|------|-----|------|
| `Padding` | `8, 6` | 水平8px，垂直6px |
| `Margin` | `0, 4, 0, 0` | 下方间距4px |
| `CornerRadius` | 4px | 圆角半径 |

### 复选框 (CheckBox) / 单选按钮 (RadioButton)

| 属性 | 值 | 说明 |
|------|-----|------|
| `Margin` | `0, 2, 0, 0` | 下方间距2px |
| `Padding` | `4, 0` | 内容与控件间距4px |

### 滑块 (Slider)

| 属性 | 值 | 说明 |
|------|-----|------|
| `Margin` | `0, 8, 0, 0` | 下方间距8px |
| `Padding` | `0, 4` | 垂直内边距4px |

### 进度条 (ProgressBar)

| 属性 | 值 | 说明 |
|------|-----|------|
| `Margin` | `0, 8, 0, 0` | 下方间距8px |
| `Height` | 4px | 进度条高度 |

### 列表框 (ListBox) / 组合框 (ComboBox)

| 属性 | 值 | 说明 |
|------|-----|------|
| `Margin` | `0, 4, 0, 0` | 下方间距4px |
| `Padding` | `8, 4` | 内部填充 |

### 滚动视图 (ScrollViewer)

| 属性 | 值 | 说明 |
|------|-----|------|
| `Margin` | `0` | 无默认边距 |
| `Padding` | `0` | 无默认填充 |

### 分组框 (GroupBox)

| 属性 | 值 | 说明 |
|------|-----|------|
| `Margin` | `0, 0, 0, 16` | 下方间距16px |
| `Padding` | `12, 8` | 内部填充 |
| `Header` 间距 | `0, 0, 0, 8` | 标题与内容间距8px |

| `Margin` | `0` | 无默认边距 |

### 菜单 (Menu) / 上下文菜单 (ContextMenu)

### 状态栏 (StatusBar)

### 树视图 (TreeView)

### 图片 (Image)

| 属性 | 值 | 说明 |
|------|-----|------|

| 属性 | 值 | 说明 |
|------|-----|------|
| `Margin` | `0` | 无默认边距 |
| `RowSpacing` | `8` | 行之间默认间距 |
| `ColumnSpacing` | `8` | 列之间默认间距（常用值：10,12,14,16） |

#### WrapPanel
| 属性 | 值 | 说明 |
|------|-----|------|
| `Margin` | `0` | 无默认边距 |
| `ItemWidth` | `自动` | 默认自动宽度 |
| `ItemHeight` | `自动` | 默认自动高度 |

#### Canvas
| 属性 | 值 | 说明 |
|------|-----|------|

## 间距使用原则

1. **一致性**：相同类型的元素使用相同的间距值
2. **层次感**：通过不同间距值创建视觉层次
3. **呼吸感**：保持足够的留白，避免界面拥挤
4. **对齐**：使用网格系统确保元素对齐
5. **响应式**：在不同屏幕尺寸下保持间距比例

## 示例代码

```xml
<!-- 使用规范间距的示例 -->
<StackPanel Spacing="8">
    <TextBlock Text="用户名" Margin="0, 0, 0, 4"/>
    <TextBox Watermark="请输入用户名" Margin="0, 0, 0, 16"/>
    
    <TextBlock Text="密码" Margin="0, 0, 0, 4"/>
    <TextBox Watermark="请输入密码" Margin="0, 0, 0, 16"/>
    
    <StackPanel Orientation="Horizontal" Spacing="8">
        <Button Content="登录" Classes="accent"/>
        <Button Content="取消"/>
    </StackPanel>
</StackPanel>
```
