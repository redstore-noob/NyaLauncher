# 03 · 布局与间距规范

> 本规范定义 NyaLauncher Avalonia 应用中所有控件的间距标准，基于实际项目代码分析制定。
> 目的是保证界面一致性与可维护性——**新写页面时请对照本表取值，不要凭感觉填数字**。

---

## 1. 基础间距系统

采用 **2px 为基础单位** 的间距系统。

### 1.1 间距变量

| 变量名 | 值 | 用途 | 使用频率 |
|--------|-----|------|----------|
| `xxs` | 2px | 极小间距，图标与文字微调、紧密元素 | 高 |
| `xs` | 4px | 最小间距，紧凑元素内部、小分隔 | 高 |
| `sm` | 8px | 小间距，相关元素之间、按钮组间距 | 高 |
| `md` | 12px | 中等间距，一般元素分隔、卡片内边距 | 高 |
| `lg` | 16px | 大间距，区块内部 padding、主要分隔 | 高 |
| `xl` | 24px | 超大间距，区块之间分隔、标题下方 | 中 |
| `xxl` | 32px | 特大间距，页面级布局、大区域分隔 | 中 |
| `xxxl` | 48px | 巨大间距，特殊场景 | 低 |

### 1.2 常用特殊值

| 值 | 用途 | 使用场景 |
|-----|------|----------|
| `3px` | 微调间距 | 图标与文字、小元素间距 |
| `5px` | 小间距 | 紧凑布局中的分隔 |
| `7px` | 中小间距 | 按钮内边距、小卡片 |
| `9px` | 中间距 | 状态指示器间距 |
| `10px` | 中间距 | 对话框内容间距、列间距 |
| `14px` | 中大间距 | 卡片内边距、列表项间距 |
| `18px` | 大间距 | 滚动区域边距、大卡片 |
| `20px` | 大间距 | 页面区域分隔 |
| `22px` | 超大间距 | 对话框内边距 |
| `26px` | 超大间距 | 对话框内容边距 |
| `28px` | 巨大间距 | 登录框内边距 |

## 2. 控件间距规范

### 按钮（Button）

| 类型 | Padding | CornerRadius | 说明 |
|------|---------|--------------|------|
| 主要按钮 | `12, 6` | 4px | 标准按钮 |
| 窗口按钮 | `10, 0` 或 `14, 7` | 7px | 窗口控制按钮 |
| 小按钮 | `8, 4` | 4px | 紧凑场景 |
| 按钮组间距 | `0, 0, 8, 0` | — | 按钮之间水平间距 |
| 单独按钮下方 | `0, 4, 0, 0` | — | 单独按钮下方间距 |

### 文本框（TextBox）

| 属性 | 值 |
|------|-----|
| `Padding` | `8, 6` |
| `Margin` | `0, 4, 0, 0` |
| `CornerRadius` | 4px |

### 复选框 / 单选按钮

| 属性 | 值 |
|------|-----|
| `Margin` | `0, 2, 0, 0` |
| `Padding` | `4, 0` |

### 滑块（Slider）

| 属性 | 值 |
|------|-----|
| `Margin` | `0, 8, 0, 0` |
| `Padding` | `0, 4` |

### 进度条（ProgressBar）

| 属性 | 值 |
|------|-----|
| `Margin` | `0, 8, 0, 0` |
| `Height` | 4px |

### 列表框 / 组合框

| 属性 | 值 |
|------|-----|
| `Margin` | `0, 4, 0, 0` |
| `Padding` | `8, 4` |

### 滚动视图（ScrollViewer）

| 属性 | 值 |
|------|-----|
| `Margin` | `0` |
| `Padding` | `0` |

> `App.axaml` 已全局把 `ScrollViewer` 的 `Background` 设为 `Transparent`。

### 分组框（GroupBox）

| 属性 | 值 |
|------|-----|
| `Margin` | `0, 0, 0, 16` |
| `Padding` | `12, 8` |
| Header 间距 | `0, 0, 0, 8` |

### 选项卡控件（TabControl）

| 属性 | 值 |
|------|-----|
| `Margin` | `0` |
| `Padding` | `0, 8` |
| `TabItem` 间距 | `0, 0, 4, 0` |

### 菜单 / 上下文菜单

| 属性 | 值 |
|------|-----|
| `Padding` | `4, 2` |
| `MenuItem` 间距 | `0, 2, 0, 0` |
| `Separator` 边距 | `4, 2` |

### 工具栏（ToolBar）

| 属性 | 值 |
|------|-----|
| `Padding` | `4, 2` |
| Button 间距 | `0, 0, 2, 0` |

### 状态栏（StatusBar）

| 属性 | 值 |
|------|-----|
| `Padding` | `8, 4` |
| Item 间距 | `0, 0, 12, 0` |

### 树视图（TreeView）

| 属性 | 值 |
|------|-----|
| `Margin` | `0` |
| `Padding` | `4, 0` |
| `TreeViewItem` 间距 | `0, 2, 0, 0` |
| 缩进 | 16px |

### 图片（Image）

| 属性 | 值 |
|------|-----|
| `Margin` | `0` |
| `Stretch` | `Uniform` |

### 面板（Panel）

| 面板 | 属性 | 值 |
|------|------|-----|
| `StackPanel` | `Spacing` | `8`（常用值：2,3,4,5,6,7,8,9,10,12,14,16） |
| `StackPanel` | `Margin` | `0` |
| `Grid` | `Margin` | `0` |
| `Grid` | `RowSpacing` | `8` |
| `Grid` | `ColumnSpacing` | `8`（常用值：10,12,14,16） |
| `WrapPanel` | `Margin` | `0` |
| `WrapPanel` | `ItemWidth` / `ItemHeight` | 自动 |
| `Canvas` | `Margin` | `0` |

## 3. 页面布局规范

### 3.1 页面容器

| 页面类型 | Margin | 说明 |
|----------|--------|------|
| 主页面 | `40, 40, 40, 32` | 设置中心、下载页、账户管理页 |
| 版本管理 | `26, 22` | `VersionManagerPage` |
| 对话框 | `26` | 各类对话框 |
| 个人化窗口 | `26, 22` | `PersonalizationWindow` |

### 3.2 页面标题区域

| 属性 | 值 | 说明 |
|------|-----|------|
| `Margin` | `0, 0, 0, 24` | 标题下方间距（启动页为 32px） |
| `Spacing` | `8` | 标题子元素间距 |

### 3.3 卡片 / 面板

| 类型 | Margin | Padding | CornerRadius | 说明 |
|------|--------|---------|--------------|------|
| 标准卡片 | `8` | `16` | `8` | 通用卡片 |
| 下载项卡片 | `0,0,0,4` | `16,12` | `10` | 下载页项目 |
| 设置卡片 | — | `24,20` | `8` | 设置页区块 |
| 对话框内容 | `26` | — | — | 对话框内容边距 |
| 小卡片 | — | `14,10` | `8` | 紧凑卡片 |
| 标签 | — | `7,2` | `7` | 版本标签等 |

### 3.4 对话框

| 属性 | 值 |
|------|-----|
| `Margin` | `26` |
| `Spacing` | `10` |
| `Padding` | `26,22`（`PersonalizationWindow`） |

## 4. 间距使用原则

1. **一致性**：相同类型的元素使用相同的间距值
2. **层次感**：通过不同间距值创建视觉层次
3. **呼吸感**：保持足够的留白，避免界面拥挤
4. **对齐**：使用网格系统确保元素对齐
5. **响应式**：在不同屏幕尺寸下保持间距比例

## 5. 示例

```xml
<StackPanel Spacing="8">
    <TextBlock Text="用户名" Margin="0, 0, 0, 4"/>
    <TextBox Watermark="请输入用户名" Margin="0, 0, 0, 16"/>

    <TextBlock Text="密码" Margin="0, 0, 0, 4"/>
    <TextBox Watermark="请输入密码" Margin="0, 0, 0, 16"/>

    <StackPanel Orientation="Horizontal" Spacing="8">
        <Button Content="登录" Classes="accent"/>
        <Button Content="取消"/>
    </StackPanel>
</StackPanel>
```

## 6. 与主题系统的配合

- 间距与圆角是**布局常量**，不随主题变化；只有颜色走主题资源
- 卡片的背景/边框请引用 `PanelBgBrush` / `SubtleBorderBrush` 等资源键，
  具体语义见 [主题开发指南](02-theming.md#22-边框色-border)
- 设置页已有 `Border.card` / `Border.sub-card` / `TextBlock.card-title` 等样式类，
  新页面优先复用而不是重新定一套
